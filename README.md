## Organización del repositorio

```
gelatto-software/
├── README.md
├── CONTRIBUTING.md
├── .gitignore
├── docs/
│   └── bitacora/
├── equipo/
└── src/
```

| Elemento | Para qué sirve |
|---|---|
| `README.md` | Portada del proyecto: qué hacemos y quiénes somos |
| `CONTRIBUTING.md` | Reglas del equipo: ramas, commits y revisión de Pull Requests |
| `.gitignore` | Lista de lo que Git no debe guardar (`__pycache__/`, `.venv/`, `.env`) |
| `docs/` | Documentación que no cabe en el README, como las bitácoras |
| `equipo/` | Perfil de cada integrante |
| `src/` | Código fuente de las automatizaciones de los encargos |
