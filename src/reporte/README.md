# Reporte semanal de ventas · Gelatto Software

## Qué vamos a construir

Vamos a construir un reporte semanal automático de las ventas de una heladería, para que su dueño sepa cómo le fue.
Un script en Python lee las ventas de la semana, calcula cuántos helados se vendieron, qué sabor es el más pedido y en qué sede se vende más, y genera un resumen y una gráfica.
El reporte se ejecuta solo cada semana y se publica en una página web. Los datos son de ejemplo.
